A full-stack web application for job seekers and recruiters. This portal allows **job seekers** to search and apply for jobs, while **recruiters** can post and manage job listings. Built with **Java (Servlets, JSP, DAO/DTO)** on the backend, **HTML/CSS/JS/Bootstrap** for the frontend, and **MySQL** as the database.  

---

## 🚀 Features  

### 👤 Job Seeker  
- Create and manage profile  
- Browse job listings  
- Apply for jobs  
- Track application status  

### 🏢 Recruiter / Admin  
- Post new jobs  
- Update or delete job postings  
- Manage applicants  
- Dashboard to track activity  

---

## 🛠 Tech Stack  

- **Frontend:** HTML, CSS, Bootstrap, JavaScript  
- **Backend:** Java (JSP, Servlets, DAO, DTO)  
- **Database:** MySQL  
- **Server:** Apache Tomcat
